# 가나 노트

Claude 일본어 수업과 함께 쓰는 복습 웹앱 (읽기 위주 + 듣기).

- `data.js` — 수업 내용. 수업이 끝날 때마다 새 강의가 추가됩니다.
- `app.js` — 퀴즈·복습 로직 (틀린 것과 오래 안 본 것이 더 자주 출제)
- 진도와 기록은 이 기기의 브라우저에 저장됩니다.

## 올리는 법 (Netlify Drop, 무료)
1. 컴퓨터 브라우저에서 https://app.netlify.com/drop 접속 후 무료 가입
2. 압축을 푼 `kana-app` 폴더를 화면에 끌어다 놓기
3. 생긴 주소를 휴대폰 Safari로 열고 공유 → 홈 화면에 추가

## 업데이트
새 수업 후 받은 파일로 폴더를 바꾼 뒤, Netlify 사이트의 Deploys 탭에 폴더를 다시 끌어다 놓으면 됩니다.
